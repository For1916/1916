새 Mac 앱 구성

Alfred

코어 무료 · Powerpack 일회성

내 설정 (예정)

  • 앱 / 파일 / 기능 검색 (Spotlight 대비 한글·워크플로 확장)
  • Clipboard History — 텍스트·이미지·파일 경로 (최대 3개월 등 설정)
  • Workflows — 반복 작업·파일 정리·텍스트 변환 자동화

무료 (Alfred 5 코어)

  • 앱 실행·파일 검색, 웹/맞춤 검색, Fallback 검색(Google·Wikipedia 등)
  • 계산기, 사전, 북마크, Quick Look, Large Type
  • 시스템 명령(앱 종료·숨김 등), 연락처 기본 검색

유료 (Powerpack)

  • Clipboard History, Snippets·텍스트 확장(날짜·클립보드 변수 등)
  • Workflows(핫키·키워드·Remote), File Navigation·Universal Actions
  • Contacts Viewer, Music Mini Player, 1Password 연동
  • 터미널/Shell 실행, 커스텀 테마, 설정 동기화·백업

BetterTouchTool

45일 체험 → 일회성 약 $25

내 설정 (예정)

  • Right Option → 한/영 전환 (Karabiner 없이)
  • Finder Enter → 파일 열기 · F2 → 이름 변경
  • 검증 후 Karabiner 제거 후보

체험 / 유료 — 별도 무료 티어 없음. 체험·라이선스 모두 600+ 액션·전 트리거 동일

키보드

  • 전역·앱별 단축키, 좌/우 modifier 구분, 길게 누르기·Key Sequence
  • Hyper Key(예: Caps Lock → ⌘⌥⌃⇧), 텍스트 확장·스니펫
  • 조건 분기: 활성 앱·창·Wi‑Fi·시간·사용자 변수

트랙패드·마우스

  • 탭·스와이프·Tip Tap·Force Click 등 손가락 수·앱별 제스처
  • 제스처 → 창 조작·단축키·스크립트·앱 전환 등 연결

창 관리

  • 가장자리/모서리 스냅, 사용자 Snap Area, 키보드·제스처로 반쪽·최대화
  • modifier+드래그로 창 이동·리사이즈, Window Switcher, Stage Manager 연동

기타 (공식)

  • Floating Menu·위젯(HUD), 텍스트 선택 시 빠른 액션 메뉴
  • Stream Deck·매크로 패드 네이티브(Elgato 등, 제조사 앱 불필요)
  • 메뉴 막대 항목·스크린샷 편집·드로잉 제스처·매크로 체인

CleanShot X

Setapp 또는 개별 약 $35

내 설정 (예정)

  • 캡처(영역/창/전체/스크롤) — 채팅·코드 등 긴 화면
  • 지정 폴더 자동 저장 + 클립보드 동시 복사
  • 스크롤 캡처 · OCR · 화면 녹화(GIF/영상)

무료

  • 앱 자체 무료 버전 없음 — macOS 기본 캡처(⌘⇧3/4/5)·미리보기 Markup만 무료 대안

유료 (단품·Setapp)

  • 캡처: 영역·창·전체·스크롤(가로/세로), 셀프 타이머, Quick Access Overlay
  • 편집: 화살표·텍스트·단계 번호, 블러·픽셀·가리기, 배경·크롭, .cleanshot 재편집
  • OCR: 이미지·스캔에서 텍스트 복사(온디바이스), QR 코드, 30+ 언어
  • 녹화: MP4·GIF, 웹캠 오버레이, 녹화 후 간단 편집
  • 핀(화면 고정), 드래그 앤 드롭 공유, 폴더·클립보드 자동 저장
  • CleanShot Cloud: 링크 공유·협업(댓글)·비밀번호 링크 — 클라우드 없이도 앱 사용 가능, 단품은 저장 용량 제한(약 1GB급)
